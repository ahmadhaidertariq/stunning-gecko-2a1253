📋 Daily Update — the same Portfolio Update Canvas posted to your Slack self-DM, read live, by date

Asana Portfolio Health now keeps a date history: the tabs above the summary numbers show every day a snapshot has been saved (including ones saved automatically in the background — see below), and clicking one shows that day's completion/duplicates/POA/stale numbers without needing a live Asana call. "Load Live Now" pulls fresh data, gives you the full expandable per-brand detail for today, and saves that day's snapshot at the same time. A background weekly job also saves a snapshot on its own schedule even if you never open this page, so the history keeps building either way.

Daily Update reads your real "Portfolio Update" Slack Canvases live — the same Canvas your scheduled daily task already posts to your self-DM (Portfolio Snapshot, Action Tracker, Today's Key Changes, My Actions, Blockers, Tomorrow's Focus) — via the persistent "Portfolio Update — Index" canvas, which lists every day it has run so far with a one-line headline. Click Load Daily Updates, then switch between dates along the top; nothing is regenerated or reworded here, it's the exact content already posted to Slack. New days appear automatically once that scheduled task posts them and adds a row to the index — this section doesn't create or edit anything, it only reads.

POA = task name contains "POA". Violation = completed after the 3rd of its due month, or still open past the 3rd (current month used when no due date). Stale = open, no update in 7+ days. Duplicates = 2+ open tasks in the same project sharing an exact name. Timeline buckets open tasks with due dates into overdue / this week / next week / later; tasks with no due date are counted separately. Unsolved Tasks combines every currently-flagged POA/duplicate/stale/overdue item across all brands and keeps it highlighted, showing how many days it's stayed unresolved, using a daily saved record — matched by task name, so a renamed task resets its day-count. Data pulled live from Asana via your connected account each time you refresh. A snapshot of each day's totals is saved so trend arrows and unsolved-task ages can appear once a few days of history build up.
